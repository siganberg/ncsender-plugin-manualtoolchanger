## What's Changed

### ✨ New Features
- Added a warning when your firmware $31 setting exceeds the Solo Load/Unload RPM on RapidChangeSolo, so you can catch mismatched spindle speed limits before running a tool change

### 🔧 Improvements
- The TLS Aux Output setting has moved out of its own dropdown and into the Pre TLS and Post TLS event editors, keeping all tool length sensor behavior in one place
